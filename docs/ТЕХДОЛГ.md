# Техдолг

- Фото товаров в ответах API магазина остаются на CDN Тильды (static.tildacdn.com) – при отключении проекта на Тильде пропадут.
- Фильтры/сортировка каталога посетителем уходят в API Тильды и на чужом домене не отвечают.
- Корзина и оформление заказа – рантайм Тильды, заказы, заявки и рассрочка Т-Банка заблокированы (no-leads.js). Куда слать заказы с кода – решение владельца.
- На копии остаются фоновые запросы к Тильде: sysstat (телеметрия ошибок) и discounts/getactive (скидки корзины не применяются).
- tilda-port.mjs: имена sitemap-store-part1/parts зашиты; если у магазина появится part2 – читать список из sitemap-store.xml.
- shrink-images.mjs пережимает на месте: повторный запуск без нового tilda-port снова сожмёт уже сжатое.
- Видео в концептах вертикальные (VK бренда). Горизонтальный исходник показа в Милане 24.02.2024 – запросить у бренда.
