# Вариант 1 – интернет-магазин ALEX KROWN на коде (план 15.10.2026)

Задача владельца: главная в стиле «Подиум» (сейчас `/new/`) → полный магазин «Вариант 1»: каталоги, карточки
с хорошими описаниями (SEO), фиды для рекламы Google и Яндекса, избранное, полная корзина и оформление заказа.
Публикация по ссылке на GitHub Pages. Из v1 потом делаются следующие версии.

## Адреса (как на живом alex-krown.com, чтобы при переезде не было редиректов)
- `/v1/` – главная (перенос `/new/`), `/v1/catalog/`, `/v1/catalog/man/`, `/v1/catalog/woman/`,
  подразделы `/v1/catalog/man/<раздел>/` и `/v1/catalog/woman/<раздел>/` (из sitemap.xml оригинала),
  `/v1/menshoes/`, `/v1/womenshoes/`, `/v1/firmware/`, `/v1/perfume/`, `/v1/accessories/`, `/v1/hats/`, `/v1/socks/`, `/v1/sale/`.
- Карточки: `/v1/<путь товара как на Тильде>/` (`catalog/man/tproduct/<id>-<slug>`).
- `/v1/favorites/`, `/v1/order/`, текстовые страницы (о бренде, контакты, доставка, возврат, размеры, уход, документы).
- Фиды: `/v1/feeds/google.xml` (Google Merchant, RSS 2.0), `/v1/feeds/yandex.xml` (YML). `/v1/sitemap.xml`.

## Данные – `scripts/v1-data.mjs` → `src/data/v1/*.json`, фото → `public/v1/img/`
- Товары (208): из снимка API магазина (`src/data/store/`) – название, цена и старая цена первого варианта,
  размеры (варианты), цвет, «Вид товара», галерея; описание и состав – со вкладки «Описание» страницы товара
  (`src/data/pages/*tproduct*.json`), таблица размеров – со вкладки «Размер».
- Состав разделов – как на оригинале: storepart раздела из `t_store_init` страницы + все его ответы в снимке.
- Фото: до 6 на товар, WebP 480 и 960 px. Метаданные разделов (title, description, H1) – с оригинальных страниц.

## Код (Astro + Preact-острова, стиль `/new/`)
1. Данные (`scripts/v1-data.mjs`).
2. Каркас: `src/layouts/V1.astro` (head, шапка, меню, подвал, шрифты, SEO-мета) – из `/new/`.
3. Острова: `src/v1/store.ts` (корзина, избранное, localStorage), `Sheets.tsx` (шторки корзины/избранного,
   счётчики шапки), `ProductBuy.tsx` (размер, количество, в корзину, избранное), `Order.tsx` (оформление).
4. Страницы: главная, каталоги (фильтр по подразделам, сортировка, 2 карточки в ряд на телефоне),
   карточка товара (галерея, размеры, описание, состав, таблица размеров, похожие), избранное, заказ, тексты.
5. SEO: title/description/canonical/OG, JSON-LD Product+Offer, BreadcrumbList, ItemList; sitemap; фиды.
6. Публикация: сборка без копии Тильды (`TILDA_COPY=0`, `dist/_t` не публикуется), корень – оглавление версий.

## Заказ
Своего сервера нет: заказ собирается в сообщение и уходит в WhatsApp бренда (+7 983-005-58-59, с контактов
сайта; что номер в WhatsApp – не проверено). Канал – одна константа, позже меняется на приём заказов.

## Проверки
Сборка; ссылки и картинки всех страниц v1 существуют; корзина/избранное/заказ сценарием Playwright;
фиды – валидный XML, обязательные поля; Lighthouse главной, каталога, карточки (телефон ≥90, компьютер 100);
ширина 390 без вылезания; change-reviewer перед коммитами; deploy-check перед push.
