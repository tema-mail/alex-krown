# Видео в карточках товара

Как это устроено на новой главной (`/new/`), чтобы добавить видео любому товару.

## Что нужно
1. **Ролик 5–8 секунд** – самый эффектный кусок (движение, деталь, строчка). Без звука.
2. **Нарезка:** ширина 480 px, H.264, без звука, `faststart`. Выходит 300–500 КБ.
   Команда – в `scripts/collection-media.mjs`: допиши строку в `CUTS`
   (`имя: [файл-клип, начало-сек, длительность, 480, кадр-постер]`) и запусти:
   `FFMPEG=<путь к ffmpeg> node scripts/collection-media.mjs <папка с клипами>`.
   Файлы лягут в `public/home/video/<имя>.mp4` и `<имя>.webp`.
3. **В разметке карточки** у блока с фото добавь адрес видео:
   `<div class="prod__img" data-hover-video={hv('<имя>.mp4')}> <img …> </div>`.
   Больше ничего не нужно – скрипт страницы подхватит сам.

## Как ведёт себя
- Компьютер: видео играет при наведении на фото, при уходе мыши – пауза, снова видно фото.
- Телефон: играет, когда карточка почти целиком на экране (от 70 %), меньше – пауза.
- Файл видео **не качается**, пока посетитель не навёл мышь или не долистал до карточки –
  на скорость загрузки страницы видео не влияют.
- При настройке «уменьшить движение» и режиме экономии трафика видео не включаются.

## Большие видео в блоке
`<video data-film={hv('<имя>.mp4')} muted loop playsinline preload="none">` поверх `<img>`-постера:
адрес ставится после загрузки страницы, за 200 px до появления; играют только когда видны на экране.
Нарезка для большого видео – ширина 720 px, 8 секунд, до ~900 КБ.
