# Админка ALEX KROWN (Вариант 1) и сборщик админок – план 16.10.2026

## Цель владельца
Админка интернет-магазина на сайте ALEX KROWN /v1/ по образцу наших магазинов (Elite Rose, Teyes):
страницы и каталоги, товары (товар в нескольких каталогах), заявки и продажи как в Тильде, метрика
с анализом товарного спроса, SEO-аналитика, «Точка А». И отдельно – скилл и агенты, которые умеют
собирать любую админку по типу проекта и копят правила в памяти.

## Модули админки (/v1/admin/)
| Модуль | Что делает | Данные | Сохранение |
|---|---|---|---|
| Страницы | список страниц сайта по типам (главная, каталоги, карточки, текстовые), ссылки, SEO-поля | sections.json, pages.json | GitHub API (как Elite Rose) |
| Каталоги | разделы и подразделы, порядок товаров, товар может стоять в нескольких | sections.json (uids) | GitHub API |
| Товары | список, поиск, фильтр по каталогу, редактор (основное, цены и размеры, фото, описание и состав, каталоги, SEO), скрыть/показать, добавить, удалить | products.json | GitHub API |
| Заявки | формы без оплаты: имя, телефон, источник, этап (новая – в работе – закрыта) | сервер заказов (решение владельца) | сервер |
| Продажи | заказы как в Тильде: номер, дата, клиент, товары и размеры, сумма, доставка, статус оплаты (оплачен / не оплачен / частично / возврат), статус заказа (новый – подтверждён – собран – отправлен – получен – отменён), источник (UTM) | сервер заказов | сервер |
| Метрика | трафик, источники, устройства, города, цели; товарный спрос: просмотры – покупки – конверсия, ABC по выручке, «смотрят, но не покупают», спрос по каталогам | Метрика API (счётчик 112281637) | закрытый сервер, пароль |
| SEO | запросы и страницы Search Console, доля брендовых запросов, индексация, Вебмастер | GSC, Вебмастер API | закрытый сервер |
| Точка А | срез на дату: трафик, продажи, спрос, SEO – для сравнения «было – стало» | все источники | снимок по датам |

Коммерческие данные (выручка, продажи, заказы с телефонами) в публичный репозиторий не кладутся:
до решения по серверу Точка А – закрытой ссылкой, `src/data/v1/analytics/` в .gitignore.

## Шаги (≤3 файла кода, коммит после каждого)
1. Каркас админки и вход: `layouts/Admin.astro`, стили, `GhConnect` (ключ GitHub в браузере владельца).
2. Товары: список и фильтры (`ProductsAdmin.tsx`).
3. Редактор товара и сохранение (`ProductEditor.tsx`, `gh.ts`).
4. Каталоги: товар в нескольких каталогах, порядок (`SectionsAdmin.tsx`).
5. Страницы (список и SEO-поля).
6. Продажи и заявки – интерфейс и модель данных по Тильде (данные – после решения по серверу).
7. Метрика: товарный спрос и сводка (по закрытым данным).
8. SEO и Точка А.
Скилл и агенты – параллельно, по регламенту «создание-скиллов».

## Сборщик админок (скилл + агенты + память)
- Скилл-оркестратор `админка-сборщик`: определяет тип проекта (визитка с заявками, каталог без корзины,
  магазин без эквайринга, магазин с эквайрингом, услуги с записью), выбирает модули, проверяет ключи и
  источники данных, ведёт сборку шагами, проверяет критериями приёмки, пишет правила в память.
- Агент `админка-аудитор` (только чтение): по коду и данным проекта – тип, модули, источники, риски.
- Агент `админка-приёмщик` (только чтение и браузер): проверяет админку по критериям приёмки модуля.
- Память: `memory/rules.md` скилла – решения владельца по админкам; журнал проектов.
- Переиспользует: «метрика-для-админки-на-вайбкоде» (Метрика), teyes-seo-* (SEO), change-reviewer (ревизия).
